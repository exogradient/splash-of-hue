# Project Context

## Purpose

**splash of hue teaches people to see color.** It turns hue, saturation, and brightness from abstract parameters into perceptual intuition.

Most color games test recall or vocabulary. This one decomposes perception into trainable skills, gives immediate visual feedback, and keeps technical detail available without making it the interface.

## Position

- A learning tool with game tension, not trivia with lessons attached.
- HSB for thought; CIEDE2000 for measurement.
- Quiet chrome; expressive color.
- Immediate local play; persistence is never on the critical path.
- Five focused modes instead of one mechanic stretched thin.

## Working method

1. Build in the browser.
2. Play it.
3. Keep what improves perception.
4. Remove what only explains the interface.
5. Record only decisions that remain useful to the product.
