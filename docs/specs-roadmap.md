# Roadmap

Shipped behavior belongs in `specs-journey.md`, not here.

## Next

### Share results

Share a concise text summary after a game: score, mode, and challenge link when available. Use the native share sheet with clipboard fallback. No image generation.

### Progress

Make practice visible without accounts:

- personal best per mode;
- recent score direction;
- lightweight practice cadence.

Use existing local history. Do not add a dashboard until the signal earns the space.

## Explore with evidence

### Coaching voice

Replace generic verdicts with specific, compact feedback. Play may be sharper; learning modes should coach. Validate the voice before building a large message bank.

### Snap It

An unscored image color explorer: inspect a pixel to see its HSB values and closest color name. It should strengthen transfer from the game to real images.

### Context practice

Explore simultaneous-contrast exercises only after the five shipped modes show retention and repeat use.

### Onboarding

Add guidance only if first-session completion shows that the home deck and immediate play are insufficient.

## Later

- Daily shared challenge.
- Server-validated competitive scoring.
- Global leaderboard after identity and moderation are designed.
- Real-time multiplayer.

## Evidence questions

- Does Match It practice improve Play scores?
- Which HSB channel remains the dominant error?
- Do players intentionally reveal HSB values, and does that improve later rounds?
- Does performance improve across sessions rather than within a single game?
